Rank 到 Eigenvector

Roadmap

這兩節在學什麼？

3-3 是「空間維度總帳」，3-4 是「矩陣作用下的特殊方向」。

First

先看矩陣空間的維度

row space 和 column space 看起來住在不同空間，但它們的維度永遠相同，這個共同維度就是 rank。

Then

CH3-3

Rank 與 Nullity

從 row/column space 的共同維度，到 null space 的參數數量。

一句白話核心：rank 看「矩陣真正提供幾個獨立方向」，nullity 看「Ax = 0 還剩幾個自由方向」。

細節

教材先證明 row space 和 column space 具有相同維度。若 R 是 A 的任一 echelon form，則 row operations 讓 row space 維度不變，而 column space 的維度可由 leading 1 的數量讀出。兩者最後都等於 pivot 數量。

rank(A) = dim(Row(A)) = dim(Col(A))
nullity(A) = dim(N(A))，其中 N(A) 是 Ax = 0 的解空間
重點整理
  • rank 不是矩陣有幾列或幾欄，而是獨立資訊的數量。
  • nullity 不是零的個數，而是 homogeneous system 的自由度。
  • 對 m × n 矩陣，rank 最多只能是 min(m, n)。

Theorem 3.3.1-3.3.3

Rank-Nullity 與等價定理

這一段把 pivot columns 和 free variables 放進同一個公式。

Theorem 3.3.1

Dimension Theorem for Matrices

一句白話核心：一個未知數不是 pivot，就是 free；兩者加起來就是全部欄數。
若 A 有 n columns，則 rank(A) + nullity(A) = n

rank 是 leading variables 的數量；nullity 是 free variables 的數量。教材例題的 4 × 6 矩陣有 rank = 2、nullity = 4，因此 2 + 4 = 6。

重點整理
  • n 指的是 columns 數，也就是未知數個數。
  • 不要用 rows 數去套 rank-nullity。
  • 知道 rank 就能直接得到 nullity：nullity(A) = n - rank(A)。
Theorem 3.3.2

General Solution 的參數數量

一句白話核心：Ax = 0 的參數數量，就是 nullity。
  • rank(A) = Ax = 0 general solution 中 leading variables 的數量。
  • nullity(A) = Ax = 0 general solution 中 parameters 的數量。

教材例題：若 A 是 5 × 7 且 rank(A) = 3，則

nullity(A) = n - rank(A) = 7 - 3 = 4

所以 general solution 有四個 parameters。

Theorem 3.3.3

Invertible Matrix 的等價判斷

對 n × n 矩陣，下面這些說法本質上都在說同一件事：矩陣沒有遺失任何方向。

  • A is invertible。
  • Ax = 0 只有 trivial solution。
  • RREF 是 In。
  • det(A) ≠ 0。
  • columns / rows linearly independent。
  • columns / rows span Rn。
  • columns / rows form a basis for Rn。
  • rank(A) = n。
  • nullity(A) = 0。
  • N(A)⊥ = Rn 且 Row(A)⊥ = {0}。
考試判斷法

如果你能證明其中一項成立，其他項通常就能直接引用等價定理。最常用的是：det(A) ≠ 0、rank(A) = n、nullity(A) = 0。

Theorem 3.3.4-3.3.5

Overdetermined 與 Underdetermined Systems

多方程不一定無解，少方程也不一定有解；rank 才是關鍵。

一句白話核心：consistent 時，解的自由度由 n - rank(A) 決定。

細節

若 Ax = b 是 consistent，且 A 是 m × n、rank(A) = r，則 general solution 含有 n - r 個 parameters。這是 Theorem 3.3.4。

consistent Ax = b ⇒ number of parameters = n - r
重點整理
  • overdetermined: m > n，方程比未知數多，至少有某些 b 會讓系統 inconsistent。
  • underdetermined: m < n，如果 consistent，必有至少一個自由參數，因此 infinitely many solutions。
  • 不要只看方程數，要看 b 是否落在 Col(A)。
教材例題 page 92

7 equations, 5 unknowns, rank 4

這是 overdetermined system。因為 n = 5、r = 4，若某個 b 讓系統 consistent，則

n - r = 5 - 4 = 1

general solution 有一個 parameter。注意：overdetermined 不代表一定無解，而是不能保證所有 b 都可解。

教材例題 page 92

5 equations, 7 unknowns, rank 4

這是 underdetermined system。它可能 inconsistent；但如果 consistent，則

n - r = 7 - 4 = 3

所以會有三個 parameters，因而有 infinitely many solutions。

教材 overdetermined 範例的解題想法

page 93-94 的系統有五條方程、兩個未知數：

x1 - 2x2 = b1,   x1 - x2 = b2,   x1 + x2 = b3,   x1 + 2x2 = b4,   x1 + 3x2 = b5

Gauss-Jordan elimination 會把限制轉成右側 b 必須滿足的條件。教材得到：

2b1 - 3b2 + b3 = 0
3b1 - 4b2 + b4 = 0
4b1 - 5b2 + b5 = 0

也就是說，overdetermined system 是否 consistent，取決於右邊的 b 是否符合這些相容條件。

Theorem 3.3.6-3.3.8

四個 Fundamental Matrix Spaces

這裡把 row、column、null space 用維度和正交關係接起來。

Theorem 3.3.6

rank(A) = rank(AT)

一句白話核心：轉置會交換 row 和 column，但不會改變獨立資訊的數量。

若 A 是 m × n 且 rank(A) = r，四個 fundamental spaces 的維度為：

dim(Row(A)) = r,   dim(Col(A)) = r
dim(N(A)) = n - r,   dim(N(AT)) = m - r
Definition 2 / Theorem 3.3.7

Orthogonal Complement

一句白話核心：W⊥ 收集所有跟 W 裡每個向量都垂直的向量。

若 W 是 Rn 的 subspace，則 W⊥ 也是 subspace，且 W 和 W⊥ 只有零向量重疊。

幾何想像

在 R2，一條 through origin 的線的 orthogonal complement 是垂直的另一條線；在 R3，一個 through origin 的平面的 orthogonal complement 是它的法向量方向。

Theorem 3.3.8

Fundamental spaces 的幾何連結

一句白話核心：null space 正好是跟 row space 垂直的所有方向；left null space 正好是跟 column space 垂直的所有方向。
N(A) = Row(A)⊥ 在 Rn 中
N(AT) = Col(A)⊥ 在 Rm 中
重點整理

3-3 的結尾不是多背兩個空間，而是要看出「解空間」和「行/列空間」其實是正交互補關係。

CH3-4

Eigenvalue 與 Eigenvector 的定義

從矩陣作用的幾何效果開始。

一句白話核心：eigenvector 是矩陣作用後方向不變的非零向量，eigenvalue 是它被放大、縮小或反向的倍數。

細節

若 A 是 n × n 矩陣，非零向量 x 滿足

Ax = λx

就稱 x 是 A 的 eigenvector，λ 是對應的 eigenvalue。若 λ 為負，方向會反向；若 0 < |λ| < 1，向量被縮短；若 |λ| > 1，向量被拉長。

重點整理
  • x 不能是 zero vector，因為零向量對任何 λ 都成立，沒有方向資訊。
  • 一般向量經過矩陣會旋轉或偏移方向；eigenvector 是少數方向仍保持在同一直線上的向量。

Theorem 3.4.1-3.4.3

Characteristic Equation：如何找 eigenvalues

把 Ax = λx 轉成 homogeneous system。

Theorem 3.4.1

Eigenvalue 的判斷公式

一句白話核心：要有非零解，就必須讓 λI - A 變成不可逆。

從 Ax = λx 開始：

Ax = λIx ⇒ (λI - A)x = 0

這個 homogeneous system 要有 nontrivial solution，係數矩陣必須 singular，因此：

det(λI - A) = 0
重點整理
  • det(λI - A) 展開後稱為 characteristic polynomial。
  • n × n 矩陣最多有 n 個 distinct eigenvalues。
  • triangular matrix 的 eigenvalues 直接看主對角線。

Eigenspaces

Eigenspace：每個 eigenvalue 的解空間

找 eigenvectors 其實就是解一個 homogeneous system。

一句白話核心：固定一個 eigenvalue 後，所有對應 eigenvectors 加上 zero vector，就是一個 null space。

細節

對應 eigenvalue λ 的 eigenspace 是

N(λI - A) = {x : (λI - A)x = 0}

教材強調：eigenvectors 本身不含 zero vector，但 eigenspace 是一個 subspace，所以會包含 zero vector。

重點整理
  • 找 eigenvalues：解 det(λI - A)=0。
  • 找 eigenvectors：把每個 eigenvalue 代回 (λI - A)x=0。
  • eigenspace basis 就是該 homogeneous system 的 basis。
Multiplicity

Algebraic multiplicity 與 geometric multiplicity

一句白話核心：一個 eigenvalue 在多項式裡重複幾次，是 algebraic multiplicity；它真的提供幾個獨立 eigenvector 方向，是 geometric multiplicity。
algebraic multiplicity = λ 在 characteristic polynomial 中作為 root 的重複次數
geometric multiplicity = dim N(λI - A)

因為 eigenspace 是 N(λI - A)，所以 geometric multiplicity 就是 (λI - A)x = 0 的自由方向數量。它永遠不會超過 algebraic multiplicity：

1 ≤ geometric multiplicity ≤ algebraic multiplicity

直覺上，algebraic multiplicity 是 characteristic polynomial 給的「名額」，geometric multiplicity 是實際解出來的「獨立方向」。同一個 root 可以在多項式裡重複很多次，但矩陣可能沒有提供同樣多個獨立 eigenvector 方向。

重點整理
  • 解 det(λI - A)=0 看到 (λ-2)^2，表示 λ=2 的 algebraic multiplicity 是 2。
  • 代回 (2I-A)x=0 後，如果 nullity 是 1，表示 geometric multiplicity 是 1。
  • 若你已經算出 dim Eλ = k，就知道這個 eigenvalue 在 characteristic polynomial 中至少重複 k 次。

Theorem 3.4.4-3.4.6

Powers、Invertibility 與新版等價定理

eigenvalue 會跟著矩陣次方一起次方化。

Theorem 3.4.4

Powers of a Matrix

一句白話核心：如果 Ax = λx，那麼 Akx = λkx。

因為 A 每作用一次，就把同一個 eigenvector 乘上一個 λ：

A2x = A(Ax) = A(λx) = λAx = λ2x

推廣到正整數 k，λk 是 Ak 的 eigenvalue，x 仍是 corresponding eigenvector。

Theorem 3.4.5

Eigenvalues and Invertibility

一句白話核心：矩陣可逆，等價於 0 不是 eigenvalue。

若 λ = 0 是 eigenvalue，代表存在非零 x 使 Ax = 0，這表示 null space 不只零向量，所以 A 不可逆。

A invertible ⟺ 0 is not an eigenvalue of A
Theorem 3.4.6

把 eigenvalue 加入 invertible checklist

3.4.6 延伸 3.3.3：對 n × n 矩陣，除了 rank、determinant、basis、one-to-one / onto 等等價條件之外，還新增：

0 is not an eigenvalue of A

所以你可以用 eigenvalue 判斷可逆性：只要 characteristic equation 的根包含 0，矩陣就不可逆；反之若沒有 0，矩陣可逆。
